# Virginia Grades 6–8 Learning Site

Bilingual (English / Simplified Chinese) learning site for Virginia grades 6–8, aligned to the Virginia Standards of Learning (SOL). 73 lessons, quizzes, flashcards, Play Labs, and SOL practice exams. No backend — progress is saved in the browser (localStorage).

**Live site:** https://erpan219.github.io/virginia-grades-6-8-learning-site/

## Editing

The whole site is one self-contained file, `index.html` (about 9 MB — text plus images embedded as data). To edit:

1. Open `index.html` in GitHub's web editor (or clone the repo).
2. Use Find to locate the text you want to change. Lesson content, quiz questions, and flashcards are all in this file.
3. Commit — GitHub Pages republishes automatically within a minute or two.

Keep every new string bilingual (English + Simplified Chinese), and don't remove the accessibility rules (e.g. `prefers-reduced-motion`).

## Origin

Built with Muse as a web artifact; this repo is the published, collaboratively editable copy. The artifact remains the master copy for major builds — re-export and re-push `index.html` after big changes.
