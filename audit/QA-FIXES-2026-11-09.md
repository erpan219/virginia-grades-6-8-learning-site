# QA fixes ready for review — November 9, 2026

Implemented and tested locally on `codex/site-audit-accounts`, based on
commit `b3e0e5e`. The owner approved publication on November 9 after reviewing
the completed fixes. This report records the prepublication checks; consult
GitHub Actions and Pages for the subsequent release status. The Cloudflare
backend, production learner records, and Free-tier configuration were not changed.

## Repairs

- **Answer-position bias:** shuffle displayed choices with a stable seed for
  each new attempt in lesson quizzes, Challenge, Daily Review, Today's Path,
  timed quizzes, SOL exams, mixed review, and printed worksheets. Canonical
  IDs, scoring, explanations, and existing stored answers remain unchanged.
  Seedless old exams keep their original order.
- **Lesson scoring and replay:** record first clicks before a correct button
  becomes disabled; replay by canonical answer ID; keep partial attempts
  stable when reopened; start fresh after completion or reassessment. Nested
  retry buttons cannot enter the parent lesson's assessment log. Printed
  answer keys use the displayed letter and keep the same order as preview.
- **Content:** make the plant experiment questions self-contained in English
  and Chinese; specify approximately normal data for the one-standard-
  deviation question; explain independent sources and the 19th Amendment
  more accurately; add the equal-step condition to the linear-table
  explanation; improve nine Economics distractors and 11 wrong-answer
  explanations. The maintained correction layer now contains 47 reviewed
  fields across eight lessons (37 added in this repair). Sources are in
  `content/README.md`.
- **Illustrations and delivery:** restore both missing SOL images using
  existing project art with accurate bilingual descriptions. Move 197 unique
  embedded illustrations to content-addressed local files without changing
  their bytes or reveal conditions. Extract three existing encoded engines
  to readable local JavaScript, retaining execution order.
- **Regression coverage:** add meaningful choice/scoring/replay, legacy
  compatibility, and asset-integrity tests; add a pinned Playwright suite and
  a read-only GitHub Actions validation workflow. CI does not publish the
  site or enforce a dependency before the existing Pages deployment.

The revision keeps 73 lessons, 559 multiple-choice questions, 545 flashcards,
and the existing 19 views. It adds no site sections or paid services.
