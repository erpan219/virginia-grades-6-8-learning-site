# Accounts and saved progress

Use these steps when **Accounts & cloud progress** is available under **More → Learners**. On a phone, open **Menu** first if needed. Accounts use usernames and generated sign-in codes; no email address is required.

## Set up the parent account

1. Choose **Set up parent account**.
2. Choose a username and enter the **Owner setup code**. The private setup code will be delivered separately; it is only for creating the first parent account.
3. Select **Create parent account**.
4. Save the username, **Sign-in code**, and **Recovery code — parent only** somewhere private, such as a password manager. The codes are shown only once. Keep the recovery code under the parent's control.
5. Select **I saved the codes** after saving them.

The setup code is not your everyday sign-in code. After setup, use **Sign in** with the parent username and generated sign-in code.

## Create a learner account

While signed in as the parent, use **Manage learner accounts** to enter a **New learner username** and **Nickname**, then select **Create learner account**. You can create up to **12 learners**.

Usernames use 3–32 letters, numbers, dots, underscores, or hyphens and start with a letter or number. Use a nickname rather than a full legal name. Save each learner's username and generated sign-in code before selecting **I saved the codes**.

The parent can use **Open progress** for a learner, then **Open account progress**. A learner can instead sign in with their own username and code. Opening account progress starts a separate study profile with automatic sync.

## Keep existing progress or use another device

- **Move existing local work into a new account:** first select the correct local learner on this device. When opening an empty learner account, explicitly check **Copy this device’s current learner progress into this empty account**, then select **Open account progress**. This option is available only for an empty account; the original local learner stays available.
- **Continue on another device:** open the same site, go to **More → Learners**, and sign in with the learner's username and code. Select **Open account progress** to load the saved work. Do not create another account for the same learner.
- **Before changing devices:** select **Save now** and wait for **Progress saved to your account.** A message such as **Saved here · sync pending** means the latest changes have not reached the cloud. Use **Check for newer save** before continuing on a device you have used before.

## Offline work and conflicting saves

Offline changes stay in the current browser. Keep that browser's data until a cloud save succeeds. When connected again, use **Save now**.

If two devices have different saves, choose **Download this progress copy** before replacing anything. Then choose **Load the cloud copy** or **Keep this device’s copy in cloud**, depending on which work you want to keep. These actions replace a copy; they do not merge learning histories.

On a shared device, use **Save and sign out** when online. If sync cannot finish, **Sign out locally · keep device copy** ends this tab's sign-in while retaining the unsynced account copy separately on this device. The server session may remain valid until it expires. Later, sign in to the same account in the same browser and choose **Resume this device’s copy**. Clearing browser data erases unsynced work.

## Lost codes and local-only learning

- **Learner lost their code:** the parent selects **Reset sign-in code** and saves the replacement. Existing learner sessions end; saved progress remains.
- **Parent lost their sign-in code:** choose **Recover parent account** and enter the parent username and recovery code. Save both replacement codes immediately. Recovery ends existing parent sessions, and the old recovery code cannot be reused. There is no email-reset option.
- **Prefer no account:** continue using the existing local learner profiles. Progress stays in that browser and does not sync across devices. Use **More → Data & backup** to export a backup periodically.
